# 신용카드 등 사용금액 소득공제 (조세특례제한법 제126조의2)

## 1. 공제 개요
근로소득자가 1년 동안 신용카드, 체크카드, 현금영수증 등으로 지출한 금액이 **총급여액의 25%를 초과**하는 경우, 초과분에 대해 일정 비율을 근로소득금액에서 공제하는 제도입니다.

## 2. 공제 대상자 및 요건
* **본인** 및 **기본공제대상자인 배우자, 직계존비속**의 사용 금액 (나이 제한 없음, 소득금액 100만 원 이하)
* **형제자매**가 사용한 금액은 공제 대상이 아닙니다.
* 맞벌이 부부의 경우, 각자 사용한 금액을 합산하거나 한쪽으로 몰아서 공제받을 수 없습니다. (결제자 기준 공제)

## 3. 공제율 및 대상 (2025년 개정 반영)
| 결제 수단 및 사용처 | 공제율 | 비고 |
| :--- | :--- | :--- |
| **신용카드** | **15%** | 기본 공제율 |
| **체크카드(직불카드), 현금영수증** | **30%** | |
| **도서, 공연, 박물관, 미술관, 영화관람료** | **30%** | 총급여 7천만 원 이하 자만 해당 |
| **수영장, 체력단련장 (헬스장) 이용료** | **30%** | **2025.7.1. 지출분부터 추가 (총급여 7천만 원 이하)** |
| **전통시장 사용분** | **40%** | |
| **대중교통 이용분** | **40%** | |

## 4. 공제 한도
| 총급여액 구간 | 기본 공제 한도 | 추가 공제 한도 (전통시장/대중교통/문화체육) | 최대 공제 한도 |
| :--- | :--- | :--- | :--- |
| **7,000만 원 이하** | **300만 원** | **300만 원** (전통, 교통, 문화체육 합산) | **600만 원** |
| **7,000만 원 초과** | **250만 원** | **200만 원** (전통, 교통 합산) | **450만 원** |

* 문화체육(도서/공연/영화/수영장/체력단련장) 추가 한도는 **총급여 7천만 원 이하**인 경우에만 적용됩니다.

## 5. 공제 제외 대상 (주의사항)
* 사업 관련 지출, 비정상적 사용액
* 자동차 구입 비용 (단, **중고 자동차** 구입 금액의 **10%**는 공제 대상 포함)
* 국민건강보험료, 국민연금, 각종 세금, 전기/수도/가스 요금, 통신비
* 아파트 관리비, 고속도로 통행료, 상품권 구입비, 리스료
* 교육비 중 보육료, 유치원비, 학교 수업료 (사설 학원비는 공제 가능)
* 면세물품 구입비

## 6. 계산 흐름
1. **최저 사용액 (문턱)** = 총급여액 × 25%
2. **공제 대상 금액** = 총 사용액 - 최저 사용액
   * 공제율이 낮은 신용카드 사용액부터 최저 사용액을 채운 것으로 간주합니다.
3. **공제액 산출** = (신용카드 초과분 × 15%) + (체크/현금 초과분 × 30%) + (문화체육 × 30%) + (전통/교통 × 40%)
4. **한도 적용**: 산출된 공제액을 기본 한도 및 추가 한도와 비교하여 최종 공제액 결정
