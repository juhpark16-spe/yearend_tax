# 자녀세액공제 (소득세법 제59조의2)

## 1. 기본공제 대상 자녀 세액공제 (2025년 개정)
종합소득이 있는 거주자의 기본공제대상자에 해당하는 자녀(8세 이상, 2017.12.31 이전 출생)에 대해 산출세액에서 다음 금액을 공제합니다.

- **1명**: 연 **25만 원** (종전 15만 원에서 10만 원 상향)
- **2명**: 연 **55만 원** (종전 35만 원에서 20만 원 상향)
- **3명 이상**: 연 **55만 원 + (2명을 초과하는 1명당 40만 원)** (종전 30만 원에서 10만 원 상향)
  * 예: 자녀 3명인 경우 55만 원 + 40만 원 = 95만 원
  * 예: 자녀 4명인 경우 55만 원 + 80만 원 = 135만 원

## 2. 당해 연도 출산 및 입양 세액공제
해당 과세기간에 출생하거나 입양 신고한 기본공제대상 자녀가 있는 경우 다음 금액을 추가 공제합니다.

- **첫째**: 연 **30만 원**
- **둘째**: 연 **50만 원**
- **셋째 이상**: 연 **70만 원**

## 3. 유의 사항
- 기본 자녀 세액공제와 출산·입양 세액공제는 중복 적용 가능합니다.
- 만 8세 미만 자녀는 아동수당 지급 대상으로 원칙적으로 제외되나, 취학 아동인 경우 공제 가능합니다.
