# 표준세액공제 (소득세법 제59조의4 제9항)

## 1. 개요 및 비교선택 원칙
근로소득자가 특별소득공제(건보·고용·주택자금), 특별세액공제(보장성보험·의료비·교육비·기부금), 월세액 세액공제를 신청하지 아니하거나, 신청한 공제의 세액감면 효과가 **13만 원**에 미달하는 경우, 산출세액에서 일괄 **13만 원**을 공제합니다.

## 2. 자동 최적화 판정 규칙
- **선택 A**: 특별소득공제 + 특별세액공제 + 월세액공제의 실제 세액 절감액 합계
- **선택 B**: 표준세액공제 일괄 13만 원
- 국세청 및 연말정산 시스템은 납세자에게 가장 유리한(A와 B 중 큰 금액) 방식을 자동 비교 적용합니다.
